# Imported bridge specifications

Each directory is named for its bridge. Read `<slug>/specs/` for feature specifications, plans, tasks and verification records. `<slug>/.specify/` is the original Spec Kit configuration and constitution from the same bridge. Repeated feature numbers are local to their bridge.

These are historical snapshots, not active tool installations. Run Spec Kit from the repository root using the root configuration and [development guide](../../docs/development.md).
