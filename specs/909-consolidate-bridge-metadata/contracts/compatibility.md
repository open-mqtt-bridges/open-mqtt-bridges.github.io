# Compatibility

Git must make the same ignore decision for each tested file or directory before and after, including new files. Bridge README license links must resolve to identical notice bytes. Preserve distinct notices in the repository and wherever they are shipped.

Frozen installs must leave tracked lockfiles unchanged. AdGuard's dev runner, transport security tests, bundle, container entry point, and release identity remain valid. The central site still builds and validates ten guides at their existing public URLs. Rust commands and existing pnpm projects require no lockfile migration.
