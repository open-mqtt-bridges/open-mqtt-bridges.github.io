# Disposable package handoff and rollback

The two private `migration-17-test-{source,target}` repositories exercised separate Actions identities with synthetic content. The package `ghcr.io/open-mqtt-bridges/migration-17-handoff-test` retained registry ID `17193962` and private visibility. No production package was changed.

1. The [source published](https://github.com/open-mqtt-bridges/migration-17-test-source/actions/runs/45204854165) `original`, digest `sha256:5e7c5ffebcf62066eec443ebb88da6fb666011ec439de4aece72e22c2540e41a`. Baseline: source linkage, inherited source access, source Actions Admin.
2. Disabled the source workflow. Granted the target **Write** in Manage Actions access. Its [handoff push](https://github.com/open-mqtt-bridges/migration-17-test-target/actions/runs/45205096261) to the existing package succeeded, and the target [pulled the original digest](https://github.com/open-mqtt-bridges/migration-17-test-target/actions/runs/45205173768). Publishing with the target's OCI source label did **not** by itself replace the existing registry source link.
3. In the package's **Repository source** section, unlinked the source, then selected **Connect Repository** on the package landing page and connected the target. The API confirmed the same private package ID with the target as source. The [target pulled the original digest again](https://github.com/open-mqtt-bridges/migration-17-test-target/actions/runs/45205471583). Relinking did not automatically remove the old Actions grant or reenable inherited permissions.
4. Removed the old source's Actions access. Dispatching its disabled workflow returned HTTP 422. After pausing the target, briefly enabled the source workflow for a negative authorization check: the [revoked writer received HTTP 403](https://github.com/open-mqtt-bridges/migration-17-test-source/actions/runs/45205613151). No `revoked-probe` version was published.
5. Rolled back: disabled the old workflow during reconfiguration, unlinked the target, reconnected the source, restored inheritance and source Admin, and removed target access. Verified that only source Admin remained. Reenabled the source, which [published a new rollback tag](https://github.com/open-mqtt-bridges/migration-17-test-source/actions/runs/45205856856) and [pulled the original digest](https://github.com/open-mqtt-bridges/migration-17-test-source/actions/runs/45205928831). Final API result: original repository, same ID, private visibility. The target publisher stayed disabled.

The disposable resources were retained. Production requires a per-package review: the proof used two private repositories; linking private production packages to a public source must preserve the approved reader set. See the [handoff checklist](../docs/migration/package-handoff.md) and [GitHub's unlink/connect instructions](https://docs.github.com/en/packages/learn-github-packages/connecting-a-repository-to-a-package#migrating-a-package-to-another-repository).
